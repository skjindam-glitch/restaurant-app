# Run Website (React/Vite)

Starts the Vite dev server for the web frontend.

```powershell
cd "d:\Claude AI Projects\Restaurant App\Website"
npm run dev
```

Website available at: http://localhost:5173

Build for production:
```powershell
cd "d:\Claude AI Projects\Restaurant App\Website"
npm run build
```

**Login:** Any email + any password works (demo mode). Pick a role from the selector.
- Manager → Dashboard
- Server → Tables  
- Cashier → Billing
- Kitchen → Kitchen
